# Resume-ready project description

**Industrial IoT-Based Manufacturing Environment Monitoring & Control System**  
**Stack:** ATmega2560, Embedded C/C++, Neo I58 GSM, P10 LED Matrix, DHT22, DS3231 RTC, UART, I2C, IPv6 HTTP, SMS

- Built ATmega2560 firmware integrating environmental sensing, time-synchronized LED visualization, cellular telemetry, and remote relay actuation.
- Implemented state-machine-based modem initialization, network bring-up, SMS processing, and IPv6 HTTP communication.
- Added nominal **60-second** JSON telemetry uploads, **2-second** sensor sampling, **4-second** P10 display rotation, and threshold-based buzzer/SMS alarms.
- Implemented remote fan/heater control and status reporting through **6 SMS commands**.

**Impact line:** Engineered a cellular-connected industrial IoT monitoring and control system combining ATmega2560 firmware, live P10 visualization, SMS-based remote actuation, and centralized environmental telemetry.

Only claim dashboard functionality, number of locations, uptime, and deployment scale when supported by external system evidence and measurements.
